# نظام إدارة معارض الفن
## نظرة عامة ومقصد المشروع
نظام إدارة معارض الفن هو تطبيق ويب يسمح للمستخدمين بإضافة، تعديل، حذف، وعرض الأعمال الفنية. الهدف من هذا المشروع هو توفير منصة سهلة الاستخدام لإدارة المعارض الفنية وتقديم تجربة المستخدم الأفضل.

## هيكل المشروع
هيكل المشروع كما يلي:
* `app`: يحتوي على كود التطبيق
* `config`: يحتوي على إعدادات التطبيق
* `database`: يحتوي على قاعدة البيانات
* `docker`: يحتوي على ملفات Docker
* `requirements`: يحتوي على متطلبات التطبيق

## تشغيل البيئة
لتشغيل البيئة، اتبع الخطوات التالية:
1. قم بتثبيت Docker و Docker Compose على جهازك.
2. قم بنسخ ملف `docker-compose.yml` إلى مجلد المشروع.
3. قم بتشغيل الأمر `docker-compose up` في Terminal.
4. انتظر حتى يتم تشغيل التطبيق.
5. افتح متصفح الويب وادخل إلى الرابط `http://localhost:8000`.
